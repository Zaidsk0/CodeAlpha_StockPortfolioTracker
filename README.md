# CodeAlpha Stock Portfolio Tracker

A simple console-based Stock Portfolio Tracker built using Python. It calculates the total investment value based on predefined stock prices and user inputs, with an option to export the summary to a text file.

## Features
- Real-time portfolio calculation using a predefined stock price dictionary.
- Validates user input for valid stock tickers and positive share quantities.
- Calculates individual stock values and total portfolio investment.
- Exports portfolio breakdown to a local `portfolio_summary.txt` file.

## Tech Stack
- Python 3
- Data Structures: Dictionaries, Lists
- File Handling (Text I/O)
